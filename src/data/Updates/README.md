## Processed outputs

Generated by `node scripts/process_updates_assets.mjs`:

- `landmarks.geojson` — all 11 KMZ Point placemarks
- `water_extent.geojson` — LatLonBox polygon for live water
- `water_extent.png` / `water_depth.png` — decoded GroundOverlay images
- `metadata.json` — provenance, bounds, validation status

No fabricated `water_depth.tif` — the source is an embedded PNG GroundOverlay, not a GeoTIFF.

## Coordinate pipeline

All features use shared `geoToWorld(lon, lat, elevation)` (`src/eye/geo/geoReference.js`):

- Input CRS: EPSG:4326 (lon, lat)
- Projected: EPSG:32643 (UTM Zone 43N)
- Scene: local ENU metres with one shared origin

## Regenerate processed assets

```bash
node scripts/process_updates_assets.mjs
```
